# Soenneker.Quark.Gen.Tailwind.Modifiers

Represents the tailwind modifiers generator.

## Install

```bash
dotnet add package Soenneker.Quark.Gen.Tailwind.Modifiers
```

## What you get

- `TailwindModifiersGenerator` — Represents the tailwind modifiers generator.

## API at a glance

| API | What it does | Result / important behavior |
| --- | --- | --- |
| `TailwindModifiersGenerator.Initialize(context)` | Initializes the Tailwind Modifiers Generator so it is ready for use. | Returns no value; the requested change is complete when the method returns. |
